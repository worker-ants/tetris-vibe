# turn 5
```text
멀티플레이 기능을 추가합니다.
최대 5명이 하나의 세션에서 플레이할 수 있습니다.

host mode를 선택하면, guest가 접속하기 위한 다음 정보 사용자에게 알려줘야 합니다.
- endpoint(scheme://ip:port/path)
- 랜덤하게 생성된 password

guest mode를 선택하면, host가 제공한 정보를 입력하여 host에게 접속할 수 있도록 해야 합니다.

UI의 배치는
좌측은 자신, 우측은 다른 플레이어들의 플레이 화면이 표시되면 됩니다.
(자신의 화면은 화면 절반의 좌측 영역 전부를 사용할 수 있고, 다른 플레이어들의 화면은 영역을 분할하여 표시해주세요.)

전원이 사망하게 되면 라운드가 종료되며,
모두의 화면에 스코어를 기반으로 순위를 표시해 주세요.
(자신의 순위는 별도의 영역에 추가하고, 강조하여 표기해 주세요.)

멀티플레이 모드에서는 자기 자신에게 Pause / Resume은 가능하지만, Restart는 불가능합니다.
```
